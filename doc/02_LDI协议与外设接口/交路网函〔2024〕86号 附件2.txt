1 基本构成
本文档规定了车道设备与站级交易系统的通信接口协议，适用于高速公路收
费站标准化试点。

2.2 协议使用约定
1. 外设功能模块类型编码和外设功能模块序号，可唯一标识一个车道外设
的功能模块。例如一个车道多个车辆检测器，功能模块类型编码均为 E5H，可以
   通过序号 01H、02H、03H....进行区分。
2. 一个外设可只包含单个功能模块，如 RSU 路侧单元（功能模块类型编码
为 E1H）；也可包含多个功能模块，如多功能栏杆一体机具备电动栏杆机（E4H）、
信息显示屏（E6H）、通行信号灯(E7H)和报警器（E8H）等功能模块。
3. 单外设只作为一个 IP 设备端，其设备接口按一个功能模块进行交互。一
体化外设可作为一个 IP 设备端，也可作为多个 IP 设备端，支持对多个设备模块
信息进行组合式控制、查询和上报。
3 通讯协议说明
3.1 参数配置
接口形式：标准 RJ45 以太网接口。
通讯速率：100M/1000M 自适应。
通信协议：TCP（Transmission Control Protocol 传输控制协议）。
设备出厂默认 IP:192.168.1.100，配置功能端口 9528。
3.2 数据传输方式
服务端与客户端之间通过消息报文方式交换信息。
除特别说明外，消息的接收方必须在应答超时时间内通过消息向发送方确认
消息的处理结果。若在应答超时时间内消息的发送方未收到接收方针对所发送消
息的应答，则必须重新发送未应答的消息。
3.3 通信方式说明
3.3.1 出厂配置
在出厂模式下，车道设备作为服务端，配置软件作为客户端，适用设备配置
接口。

车道设备上电启动后，车道设备作为服务端，配置软件作为客户端；建立
TCP 连接后，车道设备服务端与客户端开始通讯：
1. 客户端主动向服务端发送设备 IP 信息配置指令，服务端应答设置结果。
2. 客户端向服务端发送设备参数配置指令，服务端应答设置结果。
3. 客户端向服务端发送设备参数采集指令，以确认设置的参数。
4. 上述参数设置成功后，客户端发送设备重启指令对服务端进行重启操作，
客户端应答重启指令接收结果；若接收成功则自动进行设备重启，并切换到工作
模式。
5. 客户端向服务端发送信息帧，服务端应返回应答指令，否则客户端将重
复发送该指令，直到达到最大重传次数：最大重传次数及重传时间间隔可动态配
置。
3.3.2 工作模式
在工作模式下，车道设备作为客户端，站级交易系统作为服务端，适用设备
配置接口、设备通用接口和设备功能接口。

服务端启动后监听通信端口，等待设备客户端连接；建立 TCP 连接后，服
务端与客户端开始通讯：
1. 客户端主动向服务端发送设备验证指令进行验证，服务端应答验证结果。
2. 验证成功后，服务端发送初始化指令对客户端进行初始化，客户端应答
初始化结果。
3. 客户端向服务端发送信息帧，服务端应返回应答指令，否则客户端将重
复发送该指令，直到达到最大重传次数：最大重传次数及重传时间间隔可动态配
置。
4. 客户端与服务端建立连接后，应定时向服务端发送监控报文，告知设备
状态。

3.4 通讯数据帧格式
服务端和客户端通讯的数据帧格式如下：
STX	VER	SEQ	LEN	DATA	CRC
数据帧中各数据域的说明如下表所示。如无特别注明，数据均采用无符号整
型编码；以字节表示的数据，均为高字节在前、低位字节在后的大端模式；对于
未定义或者保留的参数默认值填 00H。
字段	描述
STX	帧开始标志，2 字节，取值为 FFFFH
VER	协议版本号，1 字节，当前版本为 00H
SEQ	(1) 帧序列号，1 字节；
(2) 服务端主动发送帧的帧序号为 0XH，客户端响应帧的帧序号为 0XH，两帧的帧序号保持
一致，其中 X 为 1,2,3,4,5,6,7,8,9；
(3) 客户端主动发送帧的帧序号为 X0H，服务端响应帧的帧序号为 X0H，两帧的帧序号保持
一致，其中 X 为 1,2,3,4,5,6,7,8,9；
(4) 每次服务端、客户端的主动发送帧的序号自动加 1；包含多次交互的(如：RSU)通信过程，
每一次交互帧序号自动加 1。
LEN	DATA 域的长度，4 字节（高 2 字节保留，低两字节为 DATA 域长度）
DATA	帧数据内容，默认十六进制编码
CRC	从 VER 到 DATA 所有字节的 CRC16 校验值，2 字节，初始值为 FFFFH

附录 D CRC16 校验源码
//init_crc 为计算 crc 初始值，根据协议，该值为 FFFFH
#define CRC_POLYNOM	0x8408
unsigned short calc_crc16(int init_crc, unsigned char *crc_data, int len)
{
int crc = init_crc, cnt, k;
for(cnt = 0; cnt < len; cnt++)
{//loop data length
crc ^= crc_data[cnt];
for(k = 0; k < 8; k++)
{//every bit data
if(crc & 0x1)
{
crc = (crc >> 1) ^ CRC_POLYNOM;
}
else
{
crc = (crc >> 1);
}
}
}
crc = (~crc) & 0xFFFF;
return ( unsigned short )crc;
}
