# 外设接口实施计划

**状态**：`[计划中]` `[待实施]`

## 1. 文档目的
本文档用于指导后续实现与联调以下外设接口：
- 创迪自制协议接口（默认端口 `10011`）
- 信息显示屏接口（E6H）
- 通行信号灯接口（E7H）
- 报警器接口（E8H）

## 2. 当前定位
### 2.1 创迪自制协议接口
建议定位为发现/入网辅助接口，不承担主业务控制。

### 2.2 E6 / E7 / E8
建议统一纳入 LDI 设备能力层，由协议层解析后分发到设备执行层。

## 3. 历史过程痕迹
- 该计划保留了分阶段实施思路：先澄清协议边界，再统一设备能力层，再做基础通信闭环，最后完成设备适配与状态上报。
- 当前版本保留执行顺序，不删除前期判断痕迹。

## 4. 当前仍然有效的结论
- 创迪 `10011` 接口不应误实现成完整业务协议
- 协议层不应直接操作 HAL GPIO
- 设备能力必须可回到统一的状态上报模型
- E6 优先复用现有显示链路，E7/E8 优先走统一离散设备能力
