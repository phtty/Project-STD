# 光敏传感器亮度范围限制与输出钳位优化

**状态**：`[已完成]`

## 1. 问题背景

出厂产品对显示亮度有最低/最高限制要求：
- 亮度等级不能低于 4 级（最低环境光下也不能过暗）
- 亮度等级不能高于 7 级（最高环境光下也不能过亮）

优化前，`app_light_sensor_set_range(4, 7)` 被放在 `app_factory_test.c` 的工厂测试按键处理中，仅在工厂测试流程按下 TEST 按键后才生效。这意味着正常开机运行时，光敏自动调光范围为默认的 1~7，不满足出厂亮度约束。

## 2. 优化目标

将亮度范围限制（4~7）的设置从工厂测试按键触发改为上电传感器初始化时自动生效，确保光敏自动调光从开机起就在合规范围内运行。

## 3. 涉及文件

| 文件 | 层级 | 变更内容 |
|---|---|---|
| `Device/Inc/dev_light_sensor.h` | Device | 新增 `LIGHT_SENSOR_MIN_LEVEL` / `LIGHT_SENSOR_MAX_LEVEL` 宏定义；新增 `min_level`/`max_level` 字段和 `dev_light_sensor_set_range()` 声明 |
| `Device/IO/dev_light_sensor.c` | Device | 实现范围钳位逻辑（`dev_light_sensor_read` 输出前钳位）和 `dev_light_sensor_set_range()` |
| `Application/Inc/app_light_sensor.h` | Application | 新增 `app_light_sensor_set_range()` 声明 |
| `Application/Src/app_light_sensor.c` | Application | `app_light_sensor_init()` 中使用宏调用 `dev_light_sensor_set_range()`；移除工厂测试中的调用 |
| `Application/Src/app_factory_test.c` | Application | 移除 `app_light_sensor_set_range(4, 7)` 调用 |

## 4. 宏定义

在 `Device/Inc/dev_light_sensor.h` 中定义：

```c
/** 自动调光默认最低亮度等级（出厂约束：不允许低于 4 级） */
#define LIGHT_SENSOR_MIN_LEVEL  4

/** 自动调光默认最高亮度等级（出厂约束：不允许高于 7 级） */
#define LIGHT_SENSOR_MAX_LEVEL  7
```

所有使用亮度范围上下限的地方均引用这两个宏，不再使用硬编码数字。

## 5. Device 层设计

### 5.1 `light_sensor_dev_t` 结构体

```c
typedef struct {
    void *adc;
    dev_display_t *display;
    uint8_t min_level;  /* 自动调光最低亮度 (1~7) */
    uint8_t max_level;  /* 自动调光最高亮度 (1~7) */
} light_sensor_dev_t;
```

`dev_light_sensor_init()` 默认将 `min_level` 设为 1、`max_level` 设为 7。

### 5.2 `dev_light_sensor_set_range()`

```c
void dev_light_sensor_set_range(light_sensor_dev_t *dev, uint8_t min, uint8_t max)
{
    if (min < 1) min = 1;
    if (min > 7) min = 7;
    if (max < 1) max = 1;
    if (max > 7) max = 7;
    if (min > max) min = max;

    dev->min_level = min;
    dev->max_level = max;
}
```

参数钳位规则：
- `min` 和 `max` 各自限制在 1~7 范围内
- 若 `min > max`，则将 `min` 压到与 `max` 相等

### 5.3 输出钳位

在 `dev_light_sensor_read()` 中，ADC 均值映射为 1~7 亮度等级后，追加钳位：

```c
if (level < dev->min_level) level = dev->min_level;
if (level > dev->max_level) level = dev->max_level;
```

这确保无论环境光传感器读到什么值，最终输出的亮度等级都不会超出 `[min_level, max_level]` 范围。

## 6. Application 层调用

### 6.1 上电初始化时设置范围

`app_light_sensor_init()` 在 `sw_app_initcall` 阶段自动执行：

```c
void app_light_sensor_init(void)
{
    dev_light_sensor_init(&s_sensor_dev, dev_display_get());
    dev_light_sensor_set_range(&s_sensor_dev, LIGHT_SENSOR_MIN_LEVEL, LIGHT_SENSOR_MAX_LEVEL);

    const osThreadAttr_t attr = {
        .name       = "light_sensor_task",
        .stack_size = 128 * 4,
        .priority   = osPriorityLow,
    };
    g_light_sensor_task_handle = osThreadNew(app_light_sensor_task, NULL, &attr);
}
sw_app_initcall(app_light_sensor_init);
```

亮度范围在传感器设备初始化之后、RTOS 任务创建之前设置，确保自动调光任务从第一次执行起就使用约束后的范围。

### 6.2 运行时动态调整

`app_light_sensor_set_range(min, max)` 作为 Application 层包装，可在运行时通过其他模块（如工厂测试、LDI 协议指令）动态调整范围：

```c
void app_light_sensor_set_range(uint8_t min, uint8_t max)
{
    dev_light_sensor_set_range(&s_sensor_dev, min, max);
}
```

### 6.3 工厂测试中的移除

优化前 `app_factory_test.c` 中的调用：

```c
app_light_sensor_set_range(4, 7);
```

该调用已移除。工厂测试流程仍保留 `#include "app_light_sensor.h"`，因为老化阶段需要通过 `g_light_sensor_task_handle` 挂起光敏任务。

## 7. 数据流

```
app_light_sensor_init() (sw_app_initcall)
  ├─ dev_light_sensor_init()          → min_level=1, max_level=7
  ├─ dev_light_sensor_set_range(
  │      LIGHT_SENSOR_MIN_LEVEL,      // = 4
  │      LIGHT_SENSOR_MAX_LEVEL       // = 7
  │   )                               → min_level=4, max_level=7
  └─ osThreadNew(light_sensor_task)

light_sensor_task (每秒执行):
  └─ dev_light_sensor_auto_adjust()
       └─ dev_light_sensor_read()
            ├─ ADC 8次均值 → 映射 1~7
            └─ 钳位到 [min_level=4, max_level=7] → 返回 4~7
```

## 8. 设计决策

| 决策 | 理由 |
|---|---|
| 亮度范围上下限使用宏定义 | 避免硬编码魔数，修改范围只需改一处宏定义 |
| 钳位放在 `dev_light_sensor_read()` 内部 | Device 层保证输出合规，上层无需关心范围校验 |
| 范围设置放在 `app_light_sensor_init()` 而非工厂测试 | 上电即生效，不依赖人工操作 |
| `set_range()` 支持运行时调用 | 灵活性：工厂测试仍可通过该接口临时调整范围做验证 |
| `min`/`max` 自动钳位到 1~7 | 防御性编程，防止越界值破坏 PWM 输出 |
