> **协议来源**：`39山东车道费额显示器通信协议.docx`（创迪科技生产订单与技术资料，2020-07-20）

> **权威细节**：帧头登记 / 兼容矩阵 / queue 深度 → `doc/05`；内存账 → `doc/06-04 §6`；接入规则 → `doc/08`

## 1. 协议事实

- 串口通信：9600~115200bps（默认 9600）、8N1 无校验。绑定 RS485（USART1）+ RS232（USART3）双通道。
- 帧格式：`'{'`(0x7B) + 命令字(1B ASCII) + 参数长度(1B 二进制) + 参数(变长) + `'}'`(0x7D)，无 BCC/CRC。
- 目标屏幕：192×96（FONT_16 可容 6 行，协议行号 1~5 全覆盖）。

| 命令字 | 功能 | 参数 | 说明 |
|--------|------|------|------|
| `'1'` | 全屏单色 | `01红/02绿/03黄` | 文档原文「02-全屏黄」为笔误，按 03=黄实现 |
| `'2'` | 获取版本号 | `00` | 协议未定义应答格式 → 裸 ASCII 应答 PROGRAM_CODE |
| `'3'` | 单行任意显示 | 颜色 `'0'~'2'` + 行号 `'1'~'5'` + GBK 文本 | 先清行再渲染；文档颜色字段「0x30~0x31」为笔误，含 `'2'`=黄 |
| `'4'` | 全屏可编辑显示 | 颜色 + X 坐标 + Y 坐标 + 文本 | 先清屏后 word_wrap；0x0A 回车由渲染引擎换行、0x0D 被跳过 |
| `'5'` | 全屏清除 | 无 | |
| `'7'` | 亮度设定 | `'0'~'5'` | 0=自动调光（恢复光敏任务）；1~5=硬件档 {3,4,5,7,8} |
| `'8'` | 外设控制 | bit0 绿灯 / bit1 红灯 / bit2 黄闪报警 | 红灯优先（PD14 单灯互斥）；PD15 黄闪 |

无 `'6'` 命令。除 `'2'` 外协议未定义上行应答 → 单向执行不回。

上电画面（`app_sd_proto_default.c`，2026-08-17）：经 `app_default_display_register` 注册为默认显示回调，清屏后居中渲染「山东省 高速公路 欢迎您」（FONT_16 **黄字**，UTF-8 字面量 + `FONT_ENC_UTF8`，app_render 内部转 GBK 取字模）。

## 2. 已裁决歧义（2026-08-17）

| 歧义 | 裁决 |
|------|------|
| 文档第 6/7 条写作「7B 01/02 …」与字段2表「ASCII '1'~'A'」矛盾 | 按 ASCII `'1'`(0x31)/`'2'`(0x32) 实现（与字段2表一致） |
| 物理通道 | RS485 + RS232 双通道（对齐青海/四川模式） |
| 屏幕分辨率 | 192×96 |
| 版本号应答 | 裸 ASCII 应答产品程序编码 PROGRAM_CODE（`9K10212482`） |

注：`PROGRAM_CODE`（`app_boot.h` 常量）同时由主固件启动时落库 Sector1 `app_info.version`（供 IAP 0x03「上报固件状态」返回版本号，见 `doc/07` §13）；本协议 `'2'` 命令仍直接应答编译期常量，不读 Sector1。

## 3. 帧头冲突纪律（与青海/四川MTC 互斥）

山东与青海帧完全同构（`{`+cmd+len+`}`），命令字 `'1'~'5','7','8'` 全部落入青海 probe 命令集：

- **全协议 Makefile 构建**：青海 probe 先注册（源码收录序 `qh_proto_init` 在前）先认领山东帧。`'3'/'4'/'5'` 语义与青海巧合一致（行为等价）；`'1'/'2'/'7'/'8'` 语义分歧（山东 '1'=全屏单色 vs 青海 '1'=主机查询等）。
- **量产**：EIDE 目录排除纪律——山东项目须排除 `ProtocolParser_QingHai` + `ProtocolParser_SiChuang_MTC`（`{` 帧族二选一）；当前 `.eide/eide.yml` Debug 目标（贵州现行）已排除山东目录。
- **编译期互斥守卫**：山东主文件携带 `g_brace_proto_guard`（`#ifndef STD_ALL_PROTO` 包裹、`__attribute__((used))`）——EIDE 量产构建多个 `{` 帧族编入即链接报 `multiple definition`，无法绕过；Makefile 全协议开发构建经 `-DSTD_ALL_PROTO` 豁免共存（probe 注册序纪律约束）。

详见 `doc/05_协议模块多协议兼容优化/01_architecture.md` §3.3 / §6。
