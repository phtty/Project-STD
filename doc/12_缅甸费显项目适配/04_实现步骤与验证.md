# 04 实现步骤与验证

## 1. 分阶段实施

### 阶段 0：现场信息收集（动手前）

- 拍摄/确认：缅甸灯板排线定义（脚数/顺序/电源脚）、TB62726 实物丝印与手册、恒流电阻阻值、WT588D 位置与语音内容（语言/短语）、C1~C3 负载、原机 5V 电源规格。
- 获取 STD 主板 HUB75 排座原理图引脚定义。
- 用示波器/逻辑分析仪抓原机 DATA/CLK/LAT/EN 实测波形（校准 §01 文档的时序推导，确认移位方向与最左/最右位）。

### 阶段 1：接口板 + 段驱动点亮

1. 制作接口板（02 文档 BOM）；用 74HCT125 转接 DATA/CLK/LAT/EN + GND + 5V。
2. 固件：新增 `dev_seg_led`（或 `app_md_seg_led`），先做**测试桩**：`app_test` 风格函数 `seg_scan_all()`——12 位逐位点亮、全亮、全灭循环。
3. TIM2 重配 1ms（或 osDelay(1) 任务）跑软件 PWM；验证 11 档占空比（示波器测 EN）。

**验证点**：全亮 6s 段位无缺划/无串位；亮度 0→10 阶梯可见且 0=全灭；EN 低=亮极性正确；5V 侧波形幅度 4.5V 以上、边沿无振铃。

### 阶段 2：协议模块接入

1. 按 03 文档五步注册，probe + 定长 20B + XOR 校验（开关默认开）。
2. 命令执行层 10 命令 + 0x60 应答回源通道。
3. 参数落盘 W25Qxx（亮度/音量）。
4. 上电 6s 自检 + 复位原因判定。

**验证点**（开发机，串口助手模拟上位机）：
- 帧头错（FF E1 / 随机噪声）→ 快拒不死锁；
- 0x10/0x20/0x30 显示/闪烁/清屏与示例帧一致；
- 0x60 在 RS485、RS232 两通道分别收到 `FF E0 00`；
- 0x40 亮度断电重启保持（W25Qxx 落盘）；
- 0x50 音量生效（示波器看 WT588D DATA 或听声）；
- 0x65 自检循环 0→9→全亮，1s/档，收到新命令可打断；
- XOR 错误帧被拒（校验开启时）。

### 阶段 3：与缅甸原样机联调（逐命令对测）

按 §2 对测清单逐条执行，同一上位机/同一帧分别在原机与新机上对比行为与观感（亮度档、闪烁节奏、语音内容与节奏）。

### 阶段 4：自检/出厂与加固

- 上电自检 6s 全段亮 → 灭；WDT 复位跳过自检（人为短路喂狗验证恢复速度）。
- IWDG：拔断语音 BUSY/制造最长阻塞场景，确认不复位。
- 连续运行 24h：RS485/RS232 压力（每秒 10 帧随机命令）无卡死、段显不抖。
- 接口板批量焊接 3 块，交叉验证（排除单板焊接差异）。

## 2. 与缅甸原样机逐命令对测清单

| # | 命令 | 测试帧要点 | 通过标准 |
|---|---|---|---|
| 1 | 0x10 显示 | 12 位 0~9/A/b/C/d/E 混合 | 与原机逐位一致（含 A~E 字母位、0x00 熄灭位） |
| 2 | 0x20 闪烁 | 任意数字 | 0.5s 亮/0.5s 灭节奏与原机一致 |
| 3 | 0x30 清屏 | — | 全灭 |
| 4 | 0x40 亮度 | 0~10 全档 + 非法值（11/0xF0） | 0 灭、1~10 阶梯、非法拒收保持原档；断电保持 |
| 5 | 0x50 音量 | 0~7 + 非法 8 | 音量 8 档变化；断电保持 |
| 6 | 0x60 查询 | 两通道各发一次 | 3 字节 FF E0 00 回发及时（<100ms） |
| 7 | 0x65 自检 | — | 0→9→全亮循环，C1/C2 随档翻转；中断命令可打断 |
| 8 | 0x70 语音 | 数字段、小数点（0x3C）、短语地址、0xFE 提前结束 | 语音内容/节奏与原机一致（缅甸语资源） |
| 9 | 0x80 C1 | 0x04 / 0x00 | C1 置/清 |
| 10 | 0x90 C2 | 非 0 / 0 | C2 置/清 |
| 11 | 0x0A C3 | 非 0 / 0 | C3 置/清 |
| 12 | 上电自检 | 断电重启（非 WDT） | 全段亮 6s → 灭 |
| 13 | 帧健壮性 | 错误 XOR / 截断帧 / 乱字节 | 拒收不误显（校验开）或与原机同行为（校验关） |
| 14 | 双路 UART | RS485 与 RS232 同时发 | 两路独立响应，0x60 各回各源 |

## 3. 风险与不确定项

| # | 风险 | 影响 | 缓解/待确认 |
|---|---|---|---|
| 1 | 灯板电气参数未知（TB62726 变体 VIH、fCLK 上限、恒流电阻） | 电平转换选型、移位速率、亮度电流 | 现场拍照芯片丝印 + 手册核对；示波器实测波形（阶段 0） |
| 2 | STD HUB75 排座引脚定义未知 | 方案 A 能否不改板 | 取 STD 原理图；否则转方案 B 加焊排针 |
| 3 | 灯板 96bit 物理顺序（最左/最右位、段↔通道映射） | 显示内容镜像/乱码 | 阶段 0 抓波形 + 首版逐位点灯验证；软件侧提供"镜像翻转"编译开关兜底 |
| 4 | 上位机 XOR 字节从未被验证 | 启用校验可能拒收上位机帧 | `MD_FRAME_CHECK_XOR` 开关；联调期按实测决定开关 |
| 5 | C1~C3 负载类型未知（逻辑/功率） | DO 驱动能力不足损坏/不动作 | 现场确认负载；接口板预留 ULN2003/三极管位（BOM 选配） |
| 6 | 语音资源（语言/短语地址含义，如 0x3A）未知 | 方案 B 无法翻译；方案 A 语义依赖原芯片 | 推荐方案 A 保留 WT588D；录音/记录原机播报逐条对照 |
| 7 | 11 档亮度观感 | 软件 PWM 复刻的占空比阶梯可能与现场期望不符 | 原机对测（§2 #4）；占空比表集中定义便于调整 |
| 8 | 光敏行为（变暗发测试帧）语义不明 | 多实现或少实现 | 默认不实现，列待确认 |
| 9 | EIDE 量产口径协议互斥（FF 帧族与四川治超、`{` 帧族） | 误编入冲突协议 | excludeList 纪律 + probe 快拒 + doc/05-01 登记 |
| 10 | 缅甸现场网络需求不明 | 是否保留 TCP/UDP/LDI 影响构建口径与内存 | 现场确认；保守保留（不影响串口功能） |
