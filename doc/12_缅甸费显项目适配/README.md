# 12 缅甸费显项目适配（方案 B 接口板）

> **状态**：方案设计（未实施，2026-08-31 新建）
> **主题**：用 STD 平台（STM32F407 主板）替代缅甸费显项目 8051 主板，**保留缅甸原 12 位 7 段灯板外观**（方案 B 接口板：STD 主板 + 电平转换接口板 + 原 TB62726×6 灯板）。
> **上游事实**：8051 原机代码 `MianDian_Fee`（`/home/yystation/Program/3218008/MianDian_Fee`）；STD 硬件事实 `Core/Inc/main.h`、`Core/Src/{gpio,usart,spi,tim,adc,dma}.c`；接入规则权威 `doc/08_协议模块接入规则/`。

## 1. 方案一句话结论

STD 主板不改板（复用 HUB75 排座引出信号），外接一块**接口板**完成：① 3.3V→5V 单向电平转换（74HCT125/244）；② 12 位 7 段灯板（TB62726×6 级联 96bit）排线转接；③ 5V 灯板供电；④ WT588D 语音三线 + BUSY、C1/C2/C3 三路 DO 引出。软件侧新增缅甸协议模块（FF/E0 20 字节帧，10 命令）+ TB62726 段驱动（复刻 8051 的 1ms×11 档 EN 软件 PWM），其余（RS485/RS232 双通道、IWDG、W25Qxx 参数落盘）沿用 STD 既有框架。

## 3. 关键结论摘要

| 主题 | 结论 |
|---|---|
| TB62726 四线 | 复用 HUB75 排座：DATA=PG9、CLK=PD1、LAT=PD3、EN=PD0（软件 PWM）；改板备选：DATA/CLK/LAT=PA1/PA2/PA3、EN=TIM2_CH1(PA0) 硬件 PWM |
| 电平转换 | **74HCT125（或 74HCT244）单向缓冲**，3.3V 输入→5V 输出（VIH=2.0V，裕量大）；备选 74LVC8T245 双电源、BSS138/2N7002 分立上拉 |
| 亮度 PWM | 推荐**软件 PWM 复刻**：1ms 时基 × 11 档（占空比 = 档位/11，档 10 ≈ 91%，档 0 全灭），与原机逐毫秒一致、任意 GPIO 可作 EN；硬件备选 TIM2 CH1（ARR=10、CCR=档位，≈90.9kHz） |
| 语音 | 推荐**方案 A：位带驱动原 WT588D**（保留缅甸语音资源）；方案 B（STD RS232 TTS 板，USART6）仅在语音语言为中文且现场可更换语音板时可用 |
| 协议 | FF E0 + 命令字 + 16 数据 + 1 XOR = **20 字节**（原机 XOR 已算未比对）；新实现建议启用 XOR 校验并留编译开关；0x60 查询应答 FF E0 00（3 字节无校验） |
| 参数落盘 | 亮度/音量存 W25Qxx 独立 4KB 扇区（magic+bright+volume+CRC32），不占用 Sector1（网络配置区） |
| C1/C2/C3 | C1=PD14、C2=PD15（沿用 STD 车道灯/闪光灯 DO）、C3=PD2（空闲脚；备选 PC4/PE9），全部经接口板电平转换 |

## 4. 遗留待现场确认项（详细见各文档）

1. **灯板电气参数**：TB62726 实际型号/手册（VIH 阈值、最高移位时钟、恒流电阻阻值、EN 极性）——影响电平转换与移位速率上限。
2. **STD 主板 HUB75 排座引脚图**：排座实际引出哪些信号、是否含 5V/GND——决定方案 A 能否不改板。
3. **灯板排线定义**：96bit 与 12 位数字的物理顺序（最左位对应 DispBuf[0] 还是 [11]）、段 a~g/DP 对应 TB62726 通道（代码注释为 a-ch8/b-ch13/c-ch12/d-ch11/e-ch10/f-ch9/g-ch14，需实物核对）。
4. **上位机 XOR 字节正确性**：原设备从不校验，上位机发送的 XOR 可能从未被验证过；若启用校验联调失败则关闭开关。
5. **C1~C3 负载类型**：逻辑电平信号还是功率负载（继电器/指示灯），决定接口板是否需要 ULN2003/三极管驱动。
6. **语音资源**：WT588D 烧录的语音内容与语言（缅甸语/中文）、音量档 0~7 的现场观感。
7. **11 档亮度观感**：软件 PWM 复刻占空比 1/11~10/11 是否满足现场亮度阶梯要求。
8. **光敏用途**：原机光敏只参与自检推进与"变暗发测试帧"行为，是否需要在缅甸现场保留该行为。
