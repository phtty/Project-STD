# 02 硬件接口板方案（GPIO 选型 / 电平转换 / BOM）

## 1. GPIO 选型

### 1.1 选型原则

1. **方案 A（推荐）不改 STD 主板**：信号全部复用 HUB75 排座引脚（点阵屏被 12 位 7 段灯板替代，点阵信号全部空闲），接口板直插排座。
2. 四线（DATA/CLK/LAT/EN）尽量相邻便于走线；EN 因 PWM 频率仅 ~91Hz（1ms 粒度），**采用软件 PWM 后任意 GPIO 可作 EN**，不依赖定时器通道。
3. 方案 B（允许改板/加焊排针）：DATA/CLK/LAT 选 PA1/PA2/PA3（同端口相邻），EN 选 **PA0=TIM2_CH1**（TIM2 全库空闲，硬件 PWM）。
4. WT588D 四线（方案 A 语音）：位带 GPIO 直驱，速率要求极低（原机 300us/半拍），任意引脚。
5. C3：优先选已引出且空闲的引脚；C1/C2 沿用 STD 既有 DO（PD14/PD15）。

## 2. 电平转换（3.3V ↔ TB62726 5V）

TB62726/MBI5026 系 16ch 恒流移位寄存器典型电气参数（**按通用数据手册，需按实物芯片手册确认**）：

| 参数 | 典型值 | 备注 |
|---|---|---|
| VDD | 3.3~5.5V（灯板通常 5V） | — |
| VIH（高电平输入阈值） | ≈0.7×VDD（5V 时 ≈3.5V） | **3.3V 输出处于临界，不可靠** |
| VIL | ≈0.3×VDD | 3.3V 低电平满足 |
| 最高移位时钟 fCLK | ≥15~25MHz | 原机 131kHz 远低于上限 |
| 恒流输出 | 由 RExt 电阻设定（灯板已焊） | 无需接口板干预 |
| EN/OE | 低有效（使能输出） | 与 8051 驱动逻辑一致 |

### 2.1 三方案对比与推荐

| 方案 | 电路 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| **① 74HCT125/74HCT244（推荐）** | 4/8 通道三态缓冲，TTL 兼容输入（VIH=2.0V），VCC=5V，输出推挽 5V | 一片覆盖 4~8 线、无相位反转、速度快（ns 级）、货源广 | 单向（本场景正好单向） | DATA/CLK/LAT/EN 四线 + WT588D 3 线 + C1~C3 全部输出信号 |
| ② 74LVC8T245/74LVCH245 | 双电源 8 通道收发器（DIR 控方向） | 双向、8 通道、驱动强 | 价格高、需双电源去耦 | 需要双向或通道数多时备选 |
| ③ 分立三极管/ MOSFET（BSS138/2N7002 + 10k 上拉 5V） | 一级反相（须两级或用 PMOS 校正相位） | 成本最低 | 反相逻辑易错、占 PCB 面积、边沿慢 | 仅个别信号时兜底 |
| ④ 直连（不推荐） | 3.3V 直驱 5V 输入 | 零成本 | VIH 临界，低温/低电压下误码、段随机闪 | 仅临时调试；若实测芯片为 3.3V 容忍输入（VIH=0.45VDD=2.25V 的变体）可评估直连 |

**推荐**：74HCT125×2（8 线）或 74HCT244×2——全部输出信号（TB62726 四线 + WT588D 三线 + C1~C3）统一经 HCT 缓冲到 5V。BUSY 为 5V→3.3V 输入：F407 引脚非 5V 容忍（除 PC8/PC9/PA0~ 等 FT 引脚外），**BUSY 须经分压（2×10k）或选择 FT 引脚**（方案 B 的 PB2 非 FT → 必须分压；方案 A 的 PC13 也非 FT → 分压）。

### 2.2 电平转换电路描述（文字）

- 74HCT125 每通道：输入接 STD 3.3V 信号 → 输出接灯板/外围 5V 侧；芯片 VCC=5V、GND 与 STD 主板及灯板**共地**；未用通道输入接地防悬空。输出三态使能（OE 低有效）恒接 GND 使能。
- BUSY：WT588D BUSY（5V 推挽）→ 10k/10k 分压 → F407 输入。
- EN PWM 路径：F407 GPIO（软件 PWM）→ 74HCT125 → TB62726 EN（5V）。若用硬件 PWM（PA0）同样先过 74HCT125。

## 4. 电源

- **灯板供电**：12 位 × 7 段，每段恒流典型 20mA → 全亮最大 ≈ 12×7×20mA ≈ 1.68A。接口板 5V 输入**额定 ≥2A**（留裕量），由原机 5V 电源或 STD 主板 5V 端子供入（**现场确认原机电源规格与 STD 主板 5V 引出点**）。
- 恒流电阻 RExt 已在缅甸灯板焊接，**接口板不动电流设定**。
- 接口板 74HCT125 与分压网络由 5V 供电（HCT 自身电流 <20mA）。
- EN PWM 全灭时灯板静态电流趋近 0，无待机功耗顾虑。

## 6. 接线注意事项

1. **共地**：STD 主板、接口板、灯板、WT588D 必须单点共地，禁止隔离地。
2. **线长**：移位时钟 131kHz、边沿 ns 级，排线建议 ≤30cm；更长时 DATA/CLK 加 33Ω 源端串阻。
3. **干扰**：CLK/DATA 与 5V 大电流线分束；接口板 HCT 输出尽量靠近排座。
4. **上电顺序**：先上 STD 主板 3.3V/5V，再上灯板 5V 大电流（或同源同启）；避免 EN 悬空——上电初态固件应置 EN=1（灭）再移位。
5. **信号悬空**：未用的 HUB75 排座数据线在接口板上接地（防抖动电流）。
