# 01 项目差异分析（8051 原机 ↔ STD 平台）

> 本文所有"原机"事实均提取自 `MianDian_Fee` 源码（`TB62726.c` / `c51_time.c` / `C51_UART.C` / `main.c` / `wt588d.c` / `PORT.H` / `c51_variable.{c,h}`），非臆测。所有"STD"事实提取自 `Core/`、`Application/` 源码。

## 1. 8051 原机硬件与驱动事实

### 1.1 引脚（PORT.H）

| C1 / C2 / C3 | P2.2 / P2.1 / P2.3 | 三路 DO（排线输出；注释保留"晴兴高速"焊线变体 C2=P2^3、C1=P2^4） |

### 1.2 TB62726 驱动时序（TB62726.c，12T @11.0592MHz，1 机器周期 ≈ 1.085us）

一次完整刷新（`LedSendData`）：

```
EN=1(灭) → LAT=0 → CLK=0
12 字节 × 8 bit = 96 bit，MSB 先移，buf[0] 先移：
    置 DATA → nop → CLK=0 → 4 nop（≈4.3us 低）→ CLK=1 → 2 nop（≈2.2us 高）
    （位周期 ≈ 7.6us，96 bit ≈ 0.73ms）
→ 4 nop → LAT=1 → 4 nop（LAT 高 ≈ 4.3us）→ LAT=0 → 4 nop → EN=0(亮)
```

要点：
- **静态驱动**：TB62726×6 级联 = 96 输出 = 12 位 × 8 段（每片 16ch 供 2 位数字）。
- **移位顺序**：`g_u8LEDDispBuf[0]` 最先移入（链末端，物理上对应最右位），`[11]` 最后移入（最左位）——`ConverDisplay_ALL` 中 `ResvBuf[3] → DispTmp[11]`（最左位）、`ResvBuf[14] → DispTmp[0]`（最右位）。**物理左/右需现场核对**。
- 刷新周期由 T0 ISR（1ms）在 `g_u8LEDBrightCounter==0` 时触发一次 `LedSendData`；T0 重装值 0xFC68 → ≈1ms。

### 1.3 EN PWM 亮度（c51_time.c T0_ISR，LIGHTBRIGHT_GRADE=11）

```
每 1ms 一次 T0 中断：
  counter==0 → LedSendData()（重发 96bit + LAT）
  counter < bright → EN=0（亮），counter++
  否则            → EN=1（灭），counter++；counter≥11 → counter=0
```

- PWM 周期 = 11ms（刷新率 ≈ **90.9Hz**；代码注释"SCAN FREQUENCY:125HZ"为陈旧注释，实际以 LIGHTBRIGHT_GRADE=11 为准）。
- 占空比（亮）= 档位/11：档 0 → 全灭；档 10 → 10/11 ≈ 90.9%（非 100%，最后 1ms 固定灭）。
- 亮度合法域 0~10（命令 0x40 与 EEPROM 读均校验 `&0x0F < 11`），非法回退默认 **4**。
- **LED 全灭也能移位/锁存**：亮度只影响 EN，不影响移位通路。

### 1.4 闪烁（coruscate）

- 命令 0x20 置 `coruscate_flag=0x55`；T1 ISR（50ms，重装 0x4C1E）每 10 次（500ms）翻转 `half_second_flag`。
- `LedSendData` 中：`coruscate_flag==0x55 && half_second_flag==1` → 移入全 0（灭半秒）；否则移入真实缓冲。即 **0.5s 显示 / 0.5s 熄灭** 交替。
- 0x10 清 `coruscate_flag`（停止闪烁）。

### 1.5 段码表（c51_variable.c）

```
ledcode[16] = {0x3F,0x06,0x5B,0x4F,0x66,0x6D,0x7D,0x07,0x7F,0x6F,   // 0-9
               0x00,                                              // A(10)=熄灭
               0x77,0x7C,0x39,0x5E,0x79}                          // b C d E
```

- 段位映射（字节内）：`a=bit0, f=bit1, e=bit2, d=bit3, c=bit4, b=bit5, g=bit6, DP=bit7(0x80)`。
- TB62726 输出通道映射（代码注释）：`a-ch8, b-ch13, c-ch12, d-ch11, e-ch10, f-ch9, g-ch14`（灯板走线决定，**需实物核对**）。
- 命令 0x10/0x20 取 `ResvBuf[3..14]` 低 4 位 BCD 查表；值 0x0F 显示 'E'（表长 16 项，无 'F'，注释有误）。

### 1.6 帧格式与命令集（C51_UART.C / main.c）

- **帧 = 20 字节**：`FF`(帧头) + `E0`(地址) + 命令字(1B) + 数据(16B) + XOR(1B)。XOR 域 = `cmd ^ data[0..15]`。
- 接收状态机：FF→E0→收满 17 字节（索引 2..18）→ 第 20 字节为 XOR。
- **原机 XOR 已计算但从未比对**（比较语句被注释）——校验形同虚设。
- 溢出保护：FRAME_TEXT 超 31 字节丢弃重同步。

| 命令 | 数据语义 | 原机行为 |
|---|---|---|
| `0x10` | [3..14] 12 位 BCD（低 4 位） | 停止闪烁，12 位显示（0x00=该位熄灭） |
| `0x20` | 同 0x10 | 显示 + 0.5s/0.5s 闪烁 |
| `0x30` | — | 清屏（12 位全灭） |
| `0x40` | [3]&0x0F，须 <11 | 设亮度并写 EEPROM（0x201 亮度 + 0x202 音量，扇区 0x200 整擦） |
| `0x50` | [3]&0x0F，须 ≤7 | 设 WT588D 音量（0xE0+vol）并写 EEPROM |
| `0x60` | — | **UART1 回 `FF E0 00`（3 字节，无 XOR）**，无论命令来自哪一路 UART |
| `0x65` | — | 置自检标志：循环 0~9、全亮 0xFF、C1/C2 翻转，每档 1s（**推进受光敏=亮条件控制**，见 §1.9） |
| `0x70` | [3..31] 语音内容 | 数字段（二进制值 1~9）按 十/百/千/万 组合成地址序列逐条播报（§1.7） |
| `0x80` | [3]&0x04 | C1 = (data[3]&0x04) ? 1 : 0 |
| `0x90` | [3] | C2 = data[3] ? 1 : 0 |
| `0x0A` | [3] | C3 = data[3] ? 1 : 0 |

### 1.7 WT588D（wt588d.c）

- 字节时序（`SPI_HostWriteByte`）：CS=0 → 延时 8ms → 8 bit **LSB 先**（SCK=0，置 DATA，延时 300us，SCK=1，延时 300us）→ CS=1。**≈12.8ms/字节**（极慢，300us 为保守值）。
- 音量：`0xE0+vol`（vol 0~7，>7 钳位 7）。停止：0xFE。重复：0xF2。IO 扩展：0xF5/0xF6。
- 播报：地址 <0xDC 才发；序列以 0xFF 结束；每条发完延时 200ms 后等 BUSY 释放（BUSY=0 忙）；播报循环中喂 WDT。
- 数字→语音：解析 `ResvBuf[3..31]`，数字段（0x01~0x09 二进制值，**非 ASCII**）最长 5 位，0x3C('&lt;') 作小数点标记；组合输出「数字/十(0x0C)/百(0x0D)/千(0x0E)/万(0x0F)」地址序列；非数字非 0 字节为直接语音地址（如 0x0A 元、0x22 您好、0x24 谢谢、0x2F 免费、0x3D 系统自检）；0xFE 结束。

### 1.8 上电自检 / WDT / 参数（main.c）

- 上电：读 EEPROM 亮度(0x201)/音量(0x202)；**非 WDT 复位**时全段亮（12×0xFF）6 秒 → 全灭；WDT 复位跳过自检（快速恢复）。
- 参数持久化：STC 内部 IAP EEPROM 扇区 0x200（0x201 亮度、0x202 音量）。
- WDT：1.25s（WDT_RELOAD=0x3F），主循环喂狗（`SystemRun`），语音播报循环中同步喂狗。

### 1.9 光敏（Scan_LEDBright，主循环轮询）

- `sBright_Power=1`（P1.4 给分压供电）→ 读 P1.3 数字电平，20ms 去抖。
- 变暗（=0）：向 UART1 发送一次测试帧 `FF E0 65 + 0x3A×10 + 0x00×5`（SendString 以 0xCC 结尾）——原机"光敏触发发帧"行为。
- 变亮（=1）：若 `g_u8Test==1`（0x65 命令置位）则推进自检序列（0-9→全亮→复位，每档 1s，C1/C2 在第 1 档置 1、第 9 档清 0）。
- 结论：原机光敏**不参与显示亮度自动调节**，只参与自检推进与变暗发帧。

### 2.2 定时器与 PWM 资源

| 定时器 | 现状 | 说明 |
|---|---|---|
| TIM2 | 已 init（10kHz、周期 5000→2Hz）**无任何模块使用**（全库无 PL_TIM2 引用） | 最佳"空闲定时器"：可重配作 EN PWM 或 1ms 时基 |
| TIM3 | dev_display 行同步（1MHz/500→2kHz 基频，ISR→scan_task） | 方案 B 去掉点阵屏后释放 |
| TIM4 | dev_display OE PWM（1MHz/20→50kHz，8 级亮度） | 方案 B 去掉点阵屏后释放 |
| TIM7 | FreeRTOS 时基（HAL_IncTick 1ms） | 勿动 |

空闲引脚上可用的 PWM 通道（EN 硬件 PWM 候选）：**TIM2_CH1=PA0/PA15**、TIM5_CH1~4=PA0~PA3、TIM1_CH1=PE9、TIM1_CH4=PA11、TIM8_CH3/4=PC8/PC9、TIM12_CH1/2=PB14/PB15、TIM4_CH1/2=PB6/PD12 与 PB7/PD13（释放后）。**HUB75 排座上的引脚（PD0/1/3、PG9/10/12/15 等）均无定时器 PWM 通道**——若 EN 复用 HUB75 排座引脚，只能用软件 PWM（见 03 文档）。

### 2.3 相关框架事实

- 串口：3 路全 9600 8N1；USART1/3/6 均有 DMA RX（USART6 未启动接收，纯 TX 语音）。
- 通道：`CH_ID_RS485`(0)=USART1、`CH_ID_RS232`(1)=USART3、`CH_ID_RS232_1`(6)=USART6 **语音 TX 专用，禁止协议 bind**（doc/08 规则 8）。
- 语音 TTS 现有封装 `dev_rs232_voice.c`：`dev_rs232_voice_play(gbk_text,len)` 组帧 `FD 00 len 01 01 + GBK`；`dev_rs232_voice_volume(level)` 组帧 `FD 00 03 01 02 level`——方案 B（改接 TTS）直接复用。
- DO：`dev_io_lane_light`（PD14）/`dev_io_flash_light`（PD15）。
- 光敏：`dev_light_sensor`（ADC1 PA5，8 次均值）+ `app_light_sensor`（1s 自动调光任务，调 `display->light_level`，范围 4~7）——缅甸构建需**停用自动调光**（亮度由 0x40 命令控制）。
- 参数落盘：Sector1（16KB）为网络配置专用区；W25Qxx 末 4KB 为 LDI 配置——缅甸亮度/音量建议用 W25Qxx 独立扇区。
- 协议接入：doc/08 五步注册（`RB_PROVIDE_WEAK`→`app_proto_acquire_buf`→`app_proto_register`→`app_proto_bind_channel`→`app_proto_set_frame_queue`）+ `sw_app_initcall` + 处理任务（栈 256×4）。RB：RS485 768 / RS232 768。
- WDT：IWDG 由 `half_sec_task` 500ms 喂狗（FreeRTOS 时基 TIM7 1ms）。
- 上电流程：`init_task` 依次 splash、通道启动、`app_default_display`（注册制默认显示，可挂缅甸默认画面/自检）。

## 3. 差异对方案 B 的直接影响

| 差异点 | 影响 |
|---|---|
| 8051 5V IO ↔ F407 3.3V IO，TB62726 VIH≈0.7VDD=3.5V | 必须电平转换（02 文档） |
| EN PWM 周期 11ms/占空比档位/11，任意 GPIO 可做 | 软件 PWM 可 1:1 复刻，无需硬件 PWM 引脚（03 文档） |
| 原机移位 ~7.6us/bit（131kHz），F407 GPIO 轻松满足 | 可复刻原节奏，也可提速（需实测 TB62726 上限） |
| 原机帧 20 字节定长 + XOR 未校验 | 新实现定长探测简单；XOR 校验需决策（03 文档） |
| 原机 UART2 与 UART1 同构接收 | 新实现 RS485+RS232 双绑（同云南/贵州模式），0x60 应答回源通道（改进：原机固定回 UART1） |
| 原机 6s 上电全段亮自检 + 1.25s WDT | 新实现保留 6s 自检；IWDG 喂狗已有 half_sec_task |
| 原机光敏驱动自检推进 | 新实现 0x65 自检改为定时推进（1s/档），不依赖光敏；光敏行为仅作兼容开关 |
